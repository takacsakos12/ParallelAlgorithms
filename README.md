A feladat célja egy nagy méretű tömb rendezésének végrehajtása szekvenciális és párhuzamos módon, majd a futási idők összehasonlítása három különböző párhuzamosítási módszerrel: 
-   OpenMPI 
-   OpenMP 
-   pthread.

A kiválasztott rendezési algoritmusok: 
-   összefésüléses rendezés (Merge Sort) 
-   gyorsrendezés (QuickSort) 
-   páros-páratlan rendezés (Odd-Even Sort).
